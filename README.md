# PitaDay

<img src="public/icons/icon-192.png" alt="PitaDayのアプリアイコン" width="80">

**みんなの空きが一目でわかる、スケジュール調整アプリ。**

複数人の「参加できない日・時間」をまとめ、全員が集まれる時間帯を見つけるWebアプリです。予定の比較から候補日時の提案・投票・確定までを、一つのアプリで進められるように制作しました。

## 主な機能

- **予定の登録と比較**：終日・時間帯ごとのNGやコメントを登録し、メンバー共通の空き時間を確認。
- **候補日時の提案・投票**：集まれる日時を提案し、参加者の投票から予定を確定。
- **複数カレンダーの管理**：グループごとにカレンダーを作成し、招待リンクで共有。
- **外部連携・通知**：Googleログイン、Google Calendarの予定読み込み、プッシュ通知とリマインダー。
- **スマートフォン向けの操作**：PWA、テーマ切り替え、週の始まりの設定に対応。

## 制作で工夫した点

- 参加できない時間を入力する方式にし、メンバー全員が集まれる時間帯を自動計算。
- 予定の確認・候補の提案・投票をつなげ、日程調整の流れをアプリ内で完結させる構成。
- スマートフォンでの操作を中心に、カレンダー・通知・マイページを切り替える画面構成。
- 予定更新時の通知と定期リマインダーをCloud Functionsに分けた実装。

## 使用技術

| 分野 | 技術 |
| --- | --- |
| フロントエンド | JavaScript / HTML / CSS |
| 認証・データ管理 | Firebase Authentication / Firestore / Storage |
| サーバー処理・通知 | Cloud Functions / Firebase Cloud Messaging |
| 外部連携・配信 | Google Calendar API / Firebase Hosting / PWA |

## 公開版について

制作実績を確認できるソースコードと、架空の予定を使ったデモを掲載しています。デモでは予定の入力・比較、候補提案、自分の投票を試せます。入力内容はブラウザ内に保存され、他の人との共有・Google連携・プッシュ通知は利用できません。
